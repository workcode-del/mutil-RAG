# 多模态检索优化与对照

本次实现关注候选排序、图片表示、预算证据选择和困难负样本，不新增图关系，
不修改数据集的候选范围、划分或正确证据标注。默认参数只是待验证起点，并非已验证最优值。

## 1. 排序与重排

`reranker.top_n=50` 是送入重排的候选上限，不是评测的前 K 个结果。
`min_per_type=3` 在已有候选中按轮次为各节点类型预留名额，其余位置按融合排名填充；
候选不足时不补造节点，名额不足时优先初始排名靠前的类型，不读取答案模态。
只有一种节点类型的页面数据集自然退化为普通前 N 个重排。

`retrieval.fusion_weights` 控制各评分通道的倒数排名融合权重。
`complete_ranking=true` 时，仅让已重排候选交换它们在原排名中的位置，
未重排候选保持原位，以得到完整的重排通道排名；未重排节点不会被伪造原始模型分数。
最后仍由多通道加权融合决定输出次序。这避免了仅因接受重排就多获得一路排名贡献。

## 2. 图片与已有文本的双视图表示

`embedding.figure_text_weight=0.25`：分别单位化图片与已有描述的向量，
按 0.75 / 0.25 加权后再次单位化。保留一个证据编号、一个最终向量，复用现有索引。
这不是新增独立文本召回通道，也不生成新的图注。无描述图片仍使用原视觉向量；
表格继续使用原有图文联合编码。修复了预处理覆盖无关系图片已有描述的问题。

权重设为 0 可关闭。参数变化会使已有向量缓存失效；图模型也必须使用一致的基础表示。
新训练产物记录表示配置摘要，运行时拒绝不匹配的产物。
无摘要的旧图模型不能在非零图文权重下使用；只评估排序与选择改动时可先将权重设为 0。

## 3. 选择收益、紧凑子树与预算修复

`selection_score_source=reranker` 使用原始重排分数减去 `selection_threshold` 后的正部
作为选择奖励，不再把倒数排名分数直接当作证据置信度。未接受该评分通道打分的节点
没有独立奖励，但仍能作为连接节点或必要依赖保留。
整个查询没有重排分数时退回原始向量相似度；再无此通道则退回融合分数。
实际使用的通道记录在证据树元数据中。重排分数与向量相似度尺度不同，
应分别在验证集选阈值；默认 0.1 不是校准后的概率门槛。纯 PCST 对照仍用原有融合奖励。

`compact_trees=true`：保留正奖励主证据及连接路径，重新计算必要依赖闭包。
若仍超预算，按损失奖励与节省成本的比值逐步删除主证据并重新闭包。
这是启发式预算修复，不保证全局最优；不可分割且超预算的依赖组合不会强行保留。
附带的图注不会仅因被补入就重复获得主证据奖励。没有正收益主证据时可以返回空集合。
元数据包含主证据编号和新增依赖编号；排序召回率与最终证据 F1 仍分开计算。

## 4. 查询驱动的困难负样本

`graph_index.negative_sampling=query` 使用训练问题的向量选取同类型高相似错误证据，
而非仅找与正例相似的节点；没有同类型负例时才使用其他类型。
所有正确证据均排除，固定候选白名单始终优先。
基准运行器对跨文档数据集使用训练文档范围，其余数据集使用样本论文范围；
不加载验证或测试问题及其答案。通用训练命令默认样本范围，
可用 `graph_index.negative_scope=train` 显式改为训练文档范围。
同一问题同一类型复用负例计算；大候选集按块打分，避免一次复制整个向量矩阵。

## 5. 诊断与历史对照

报告增加 `candidate_recall`、`reranker_input_recall` 及对应分类型指标，
并保存两阶段候选编号。它们分别定位初始漏召回和重排入口截断；
最终排序指标与证据集合指标保持原定义。基准报告保存本次算法配置。

要恢复旧算法设置，在完整配置中修改以下字段，而非用本片段替换整个配置：

```yaml
embedding:
  figure_text_weight: 0.0
reranker:
  top_n: 10
  min_per_type: 0
  complete_ranking: false
retrieval:
  fusion_weights: {}
  selection_score_source: fusion
  selection_threshold: 0.0
  compact_trees: false
graph_index:
  negative_sampling: positive
```

复现旧训练负样本范围时，跨文档基准还需显式设 `graph_index.negative_scope=sample`。
图片描述保留修复和诊断输出不回退。未来的语义去冗余、通用问题槽位学习、区域视觉检索
不在本次实现中，避免引入未经验证的复杂模块。
